Servidor MCP · FinOps para agentes de IA

MCP AWS FinOps

Servidor MCP somente leitura que permite a um agente de IA (Claude, Cursor, Hermes) responder perguntas de custo AWS em linguagem natural: sete ferramentas (resumo de custos, comparação de períodos, principais direcionadores, custo por tag com % não marcado, recursos ociosos, previsão de fim de mês, explicação de anomalias), um relatório semanal e um prompt de revisão. Demonstração offline sobre dados sintéticos no formato FOCUS, validada com um agente real (Hermes + Claude Haiku); backend AWS Cost Explorer implementado com política IAM somente leitura e módulo Terraform, testado com mocks (ainda não validado em conta real).

Muralha
